## Overview

For **ArquiExpo 2026**, Puerto Rico's premier annual convention for the architecture and construction sector, Quick Metal Shop needed a high-impact digital experience for their stand. 

I designed, developed, and deployed a custom-built, vertically-oriented interactive touchscreen web application, so the sales team could show attendees the company's full catalog of architectural panels and its real-world project portfolio in a tactile, visually impressive way on a large vertical touchscreen display.

## The Challenge

The constraints were significant:
- **No existing application** or base code to build on.
- A hard deadline: the opening of the convention.
- A substantial catalog of **product images** (all at 1080×1080 resolution).
- A vertical touch interface context that had to perform flawlessly under heavy usage, including on mobile browsers.

Any lag or layout failure would be a public-facing brand embarrassment at the industry's flagship event.

## Strategic Solution

### Ideation & Architecture
I began by using **Gemini 3.1 Pro** to structure the application's conceptual architecture, defining the user experience flows, content hierarchy, and interaction model before writing a single line of code.

### Development Stack
To achieve high performance on a vertical touchscreen, I chose:

<TechStack data="Google Antigravity, Claude, Next.js, JavaScript, Netlify" />

- **Google Antigravity** (with Claude Sonnet 4.6 as the AI coding agent): leveraged for full-stack scaffolding and intelligent code generation.
- **Next.js:** framework for fast rendering and clean component architecture.
- **CSS + JavaScript:** custom styling and vertical interaction logic.
- **Netlify:** deployment platform, enabling continuous deployment.

<img src="/images/projects/app-quick-metal-shop/qmsapp2.webp" alt="Quick Metal Shop Interactive Gallery UI" />

## Core Application Features

The gallery was engineered with two distinct viewing modes for the architectural panel catalog:
1. **Single-image mode:** full-screen, one-at-a-time navigation for focused product exploration.
2. **Grid gallery mode:** multi-panel overview for browsing and comparison.

Both modes were built to accommodate the full image catalog without performance degradation, maintaining smooth 60fps interaction on the vertical touchscreen interface.

## Critical Technical Problem-Solving: iOS Safari Rendering

One of the most significant engineering challenges emerged during QA: the application was rendering incorrectly on iPhone (Safari browser). This was a critical failure point given that attendees would be accessing the experience on mobile devices throughout the event.

I diagnosed and resolved the iOS Safari-specific layout and rendering conflicts (such as vertical height adjustments and touch event handling quirks), ensuring full visual fidelity and interaction parity across all device contexts. The final application is fully responsive regardless of device, orientation, or browser engine.
